# User Stories

## Authentication

As a user,
I want to register,
So that I can access banking services.

As a user,
I want to login,
So that I can access my account securely.

## KYC

As a user,
I want to upload my documents,
So that my account can be verified.

## Transactions

As a user,
I want to transfer money,
So that I can send money to another account.

As a user,
I want to view my transaction history,
So that I can track my expenses.

## Admin

As an admin,
I want to approve KYC,
So that only verified users can use banking services.
